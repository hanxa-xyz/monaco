# /takehome-report — the deliverable

## Architecture
One build script (template: `src/monaco/templates/build_report.py`): load data → compute EVERY quoted stat
into live variables → render figures into `dsviz.FIGS` → one f-string HTML body → wrap with
`src/monaco/assets/report.css` → single self-contained file (charts base64-inlined, ~400 KB for 30+ figures thanks
to dsviz's PIL quantization). The build ends with self-verifying prints of figure count + every headline
number. **Compute before quoting** — no hand-typed numbers anywhere in prose or captions.

## Voice
GM-concise, pyramid-principle, answer-first. Numbers only when they carry weight. Zero em-dashes in body
prose (colons, commas, periods; `·` and `→` are fine). Expect a cut pass: the Faire memo went 14 pages → 8
with 33 figures computed but only ~6 visible.

## Structure
1. **Hook** in Context: the exchange rate in dollars ("one point of X is worth $Y — retention becomes a
   portfolio of priced bets"), then the question decomposed into 2–3 numbered questions mapped to sections.
2. **Summary** whose items mirror the section order exactly.
3. **Recommendations up front** (right after Summary): Part 1 Operational Adoption, Part 2 Strategy &
   Experimentation using the sizing skill's template, plus the deprioritized-levers box.
4. Evidence sections, each closing with a grey `.assume` box of that section's assumptions.
5. Follow-ups & assumptions. Optional deep-dive sections go LAST, tagged `[Optional]`, with an opener
   saying the recommendation stands without them.
6. Two-artifact split: this memo + a breadth EDA notebook holding every held-back chart, with a closing
   cell mapping memo ↔ notebook.

## Editing traps (all real, all hit once)
- f-string body: single `{}` are live Python; double every literal brace. Patch scripts that insert HTML
  must use SINGLE braces for live values.
- `assert anchor in t` before every `t.replace()`; failed assert = nothing saved, re-apply everything.
- Escape `<` as `&lt;` anywhere routed to raw HTML.
- HTML comments cannot nest: hide sections with `<!-- HIDDEN: +restore note -->`, but stash sections that
  CONTAIN hidden blocks as plain (non-f) string variables instead.
- Hide, never delete; strip `img()` calls inside hidden blocks (no dead base64); keep figures computed.
- Prefer double-quoted Python strings for prose (apostrophes break cells).

## Standing verification after EVERY build
1. Figure count (`data:image/png` occurrences) matches expectation.
2. Brace-leak regex over comment/CSS/base64-stripped HTML == 0.
3. Tag balance (`<li>`/`</li>`, `<ul>`, `<ol>`).
4. Extract and **Read** at least the changed PNGs.
5. After renumbering sections: grep every `§N` reference; after row changes: grep `Row [123]`.
6. Regenerate any PDF/DOCX exports right before submitting (they go stale silently); `qlmanage -t` to
   eyeball a .docx (no LibreOffice on this machine).
